# Система управления картинками KuzPotato

## Как использовать картинки

### 1️⃣ Текущая конфигурация
В файле `script.js` в начале кода есть переменная для управления путём к картинкам:

```javascript
const IMAGE_BASE_PATH = ''; // оставь пусто если картинки в корне
```

### 2️⃣ Варианты использования:

#### Вариант 1: Картинки в корне проекта (текущий)
```javascript
const IMAGE_BASE_PATH = '';
```
Файлы картинок должны быть в той же папке, что и `.html` файлы:
```
📁 Проект картошка/
  ├─ 1.jpg
  ├─ 2.jpg
  ├─ 3.jpg
  ├─ script.js
  └─ index.html
```

#### Вариант 2: Картинки в отдельной папке
```javascript
const IMAGE_BASE_PATH = 'images/';
```
Структура проекта:
```
📁 Проект картошка/
  ├─ 📁 images/
  │  ├─ 1.jpg
  │  ├─ 2.jpg
  │  ├─ 3.jpg
  ├─ script.js
  └─ index.html
```

#### Вариант 3: Картинки на интернет сервере
```javascript
const IMAGE_BASE_PATH = 'https://example.com/potato/';
```

### 3️⃣ Как добавить новый товар с картинкой

Добавь объект в массив `products` в `script.js`:

```javascript
{ 
    id: 6,                          // Уникальный ID
    name: 'Мой новый картофель',    // Название
    category: 'premium',             // Категория: premium, farm, early, universal
    price: 99,                       // Цена в рублях
    unit: 'кг',                      // Единица измерения
    desc: 'Описание товара',         // Описание
    img: 'my-potato.jpg',            // 👈 Просто имя файла! Путь добавится автоматически
    chars: { 
        'Сорт': 'Мой сорт', 
        'Вес': '1 кг', 
        'Происхождение': 'Кемерово',
        'Хранение': '3-5°C' 
    } 
},
```

### 4️⃣ Поддерживаемые форматы картинок
- `.jpg` / `.jpeg` - Рекомендуется (хороший баланс размер/качество)
- `.png` - Для картинок с прозрачностью
- `.webp` - Современный формат (если браузер поддерживает)
- `.svg` - Для иконок и логотипов

### 5️⃣ Рекомендации
- **Размер картинок**: 800-1200px в ширину
- **Размер файла**: 100-300KB на картинку
- **Соотношение сторон**: 1:1 (квадрат) или 4:3 (прямоугольник)

### 6️⃣ Где картинки используются
1. **Главная страница** - 3 товара в популярных
2. **Каталог** - все товары
3. **Страница товара** - выбранный товар
4. **Корзина** - товары в корзине
